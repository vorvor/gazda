# Media Export Files
 
Media Library Export Form allows users to download all media files from the site in a ZIP archive.
It provides two options for organizing the files:
either in a single folder or nested within their respective directories.
 
## Installation
 
You can install this module with two ways.
 
Via Composer
 
1. Navigate to your Drupal root directory.
 
2. Run the following command to install the module:
 
    ``` bash
 
    composer require drupal/media_export_files
    ```
 
3. After the module is installed, enable it using
Drush or through the Drupal admin interface.
 
Manual Installation
 
1. Download the module from [Drupal.org](https://www.drupal.org/project/media_export_files).
2. Extract the downloaded file and put it in your module folder.
 
## Configuration
 
1. Download and extract files in the module folder.
2. Enable module from the module list.
3. Go to admin menu >> configuration >>media>> media export files.
4. Now you can download media library.
